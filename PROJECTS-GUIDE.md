# Projects guide / دليل المشاريع

The Projects section now contains 18 projects, including eight newly added course and personal projects. Project content is stored in `content.json` and embedded in `script.js` for offline opening of `index.html`. When editing a project, update both locations or regenerate the embedded data.

The two library projects are kept separate: the earlier JavaFX library application and the new Java + SQL school library management system.

New project images are not claimed to be real screenshots; the cards use abstract placeholders.
