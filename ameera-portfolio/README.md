# Ameera Faqeh — Personal Portfolio (2026)

Responsive bilingual English/Arabic portfolio with black and cool-pink theme.

## Run locally

Open a terminal inside this folder and run:

```bash
python -m http.server 8000
```

Visit http://localhost:8000. Opening `index.html` directly may block loading `content.json` due to browser security restrictions.

## Files

- `index.html`: semantic page structure, SEO and contact links.
- `style.css`: responsive design and motion.
- `script.js`: language switching, filtering, scroll effects.
- `content.json`: editable projects and certificates.
- `assets/ameera-photo.jpg`: personal portrait.
- `assets/orla-logo.png`: ORLA logo.

## Update content

Edit projects/certificates in `content.json`, and copy new photos into `assets/`. Project illustrations are decorative, not actual screenshots.
